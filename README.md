# Native Component Starter Package

This package contains safe placeholders for the requested component names.
It does not include compiled ARM executables, game-memory access, ESP logic,
privileged patching, process hooks, or kernel modules.

## Files
- sock64, socu64: ARM64 placeholder documentation
- socs32, socu32: ARM32 placeholder documentation
- TW, VNG: example text configuration files
- HakmeDev: non-executing placeholder script
- kernels64: kernel-module placeholder documentation

To build legitimate native components, use the Android NDK and implement
documented, authorized functionality. These placeholders are not executable
native binaries.
